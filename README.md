# 🌿 Map My Herb

Map My Herb is a web-based application that helps users **discover, identify, and locate medicinal plants**.
The platform provides information about herbs, their medicinal uses, and their geographical locations through an interactive interface.

This project aims to promote awareness of **traditional medicinal plants and herbal knowledge** while providing an easy-to-use digital platform for exploring them.

---

# 🚀 Features

* 🌱 Explore different medicinal plants
* 🗺️ Interactive map to locate herbs
* 📖 View detailed information about each herb
* 🔍 Search and filter herbs by name or category
* 📍 Display herb locations using geolocation
* 💻 User-friendly web interface

---

# 🧠 Project Purpose

Medicinal plants have been used for centuries in traditional medicine.
Map My Herb helps preserve and share this knowledge by providing a **digital platform that connects plant information with geographic locations**, making it easier for users to learn about herbal medicine.

# ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/yourusername/Map-My-Herb.git
cd Map-My-Herb
```

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 3️⃣ Run the Application

```bash
python app.py
```

---

### 4️⃣ Open in Browser

